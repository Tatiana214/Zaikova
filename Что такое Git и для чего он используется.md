Что такое Git и для чего он используется?
- Git - программа ,которая помогает сохранять разные версии своего кода 
В чем разница между централизованными и распределенными системами контроля версий?
- В централизованной все хранят код на одном компьютере . В распределенной у кажного своя копия на компьютере
